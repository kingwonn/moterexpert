# 高速风筒数字马达与 FOC 控制：从产品调研到失效管控

以戴森（Dyson）、追觅（Dreame）、徕芬（Laifen）等高速吹风机为样本，把一颗 10 万转级数字马达从"拆开看"讲到"管到底"。全书回答三个层层递进的问题：

1. **它是什么？** —— 从真实产品调研入手：高速风筒马达由哪些部件组成（定子、转子、叶轮、轴承、驱动板），各家采用什么技术路线，为什么这样设计（第 1 章）。
2. **它为什么能转？** —— 回到电控第一性原理：从洛伦兹力与法拉第定律出发，建立"电压→电流→磁动势→磁链→转矩→转速→功率"的完整物理量链条，推导 PMSM 的 dq 数学模型与机械动力学方程，进而完整展开磁场定向控制（FOC）：坐标变换、电流环、SVPWM、无感观测器（第 2、3 章）。
3. **它如何工作、如何失效、如何管控？** —— 沿时间轴逐步解析从按下开关到满速运行的每一步，给出全部关键参数的定义、典型值与作用，并以 FMEA 方法系统梳理失效模式与软硬件保护、量产管控手段（第 4、5 章）。

> **执行入口：[《总体方案书》](docs/19-总体方案书.md)** —— 全书的执行总纲：已确证结论、系统架构、四期实施计划（含当前在途工作）、定版参数表、实验计划、开放问题与总验收标准。只读一份文档就从这里开始。

## 设计总纲（三句话）

1. **真实世界校准程序世界**。示波器、电阻测量、热电偶等真实仪器提供绝对基准；估算算法必须设计成"能吃进真实测量并收敛"的结构——锚定、个体标定、双通道互校（附录 D 的三个万能修正）——让程序里每个推算量都有第二本账。仿真已验证：模型参数偏差 ±20% 时，纯积分漂移 15.6 K，电阻锚定后收敛到 3.3 K。
2. **分层保护，而非单点保护**。硬件逐拍限流兜住微秒级事故；I²t、最大电流、最大功率限制管秒级慢过载；温度闭环（Thermal Governor）管分钟级热积累（第 7/9/11 章五层防线）。
3. **接受"体面退场"**。不可恢复的退化——三相不平衡确证、降载后仍持续过热、退磁棘轮坐实——不硬扛：黑匣子留证 → 锁机（LOCKED 态）→ 引导返厂。把"突然爆炸"变成"有尊严的退休"，把每一台返厂机变成机群学习的标注样本（第 9 章趋势档案 + 附录 C 数据飞轮）。

## 全书基准机

为了让所有数值可复算、可交叉验证，第 2～5 章共用一台与第 1 章调研结论一致的"基准机"（三相高压无感 FOC 路线，教学设定值，不对应任何具体量产机型）：

| 参数 | 取值 | 说明 |
|---|---|---|
| 额定转速 $n$ | 110 000 rpm | 品类典型值 |
| 极对数 $p$ | 2（4 极） | 高速机典型选择 |
| 电频率 $f_e$ | 3.667 kHz | $f_e = np/60$ |
| 电角速度 $\omega_e$ | 23 038 rad/s | $\omega_e = p\,\omega_m$ |
| 轴功率 / 额定转矩 | 100 W / 8.7 mN·m | $T = P/\omega_m$ |
| 母线电压 $U_{dc}$ | 310 V DC | 市电整流高压路线 |
| PWM 频率 $f_{PWM}$ | 64 kHz | 满足载波比要求 |
| 永磁磁链 $\psi_f$ | 6.0 mWb **[估计值]** | 见下方说明 |
| 相电阻 / 相电感 | 15 Ω / 5 mH **[估计值]** | 高压细线多匝绕组量级 |
| 转动惯量 $J$ | $3\times10^{-7}$ kg·m² **[估计值]** | 微型转子量级 |

> **关于 $\psi_f$ 的取值演进**：电机本体参数无公开数据，各章按电压预算自洽反推——第 2 章用无裕量上界 7.0 mWb 演示单位换算；第 3 章按标称母线 310 V、留 5～10% 裕量初算为 6.5 mWb；第 4 章进一步计入满载母线纹波谷值（≈282 V）精化为 6.0 mWb；第 5 章沿用 6.0 mWb。各章内部完全自洽，差异即"电压预算的精度层级"，文中均有注记。

## 全书符号表

| 符号 | 含义 | 单位 |
|---|---|---|
| $n$ | 机械转速 | rpm |
| $\omega_m$ / $\omega_e$ | 机械 / 电角速度（$\omega_e = p\,\omega_m$） | rad/s |
| $f_e$ / $f_{PWM}$ | 电频率 / PWM 载波频率 | Hz |
| $p$ | 极对数 | — |
| $\psi_f$ | 永磁磁链（幅值不变约定） | Wb |
| $k_e$ | 反电动势常数（$k_e = p\,\psi_f$，相峰值约定） | V·s/rad |
| $R$、$L_d$、$L_q$ | 相电阻、d/q 轴电感 | Ω、H |
| $i_d$、$i_q$ / $u_d$、$u_q$ | dq 轴电流 / 电压 | A / V |
| $T_e$、$T_L$ | 电磁转矩、负载转矩（$T_e=\tfrac{3}{2}p\psi_f i_q$，表贴 $L_d\approx L_q$） | N·m |
| $J$、$B$ | 转动惯量、粘滞摩擦系数 | kg·m²、N·m·s |
| $U_{dc}$、$U_{max}$ | 母线电压、SVPWM 线性区最大相电压幅值（$U_{dc}/\sqrt3$） | V |
| $N_c$ | 载波比（$f_{PWM}/f_e$） | — |
| $G$ | 动平衡等级 | mm/s |
| DN | 轴承直径×转速积 | mm·rpm |

全书坐标变换取**幅值不变（amplitude-invariant）约定**，故转矩方程带 $\tfrac{3}{2}$ 系数。

## 建议阅读路线

- **想快速了解产品与行业**：只读第 1 章，重点看 §1.5 两条驱动路线对比与 §1.7 共性架构抽象。
- **想系统建立理论**：按 2 → 3 章顺序精读，第 2 章的 dq 模型推导是第 3 章 FOC 的直接地基，两章共用同一套符号与基准机。
- **做固件 / 电控开发**：以第 4 章的九步时间轴为主线，随时回查第 3 章对应算法小节，再用第 5 章 §5.1 参数总表与 §5.4 保护策略对照自己的工程实现。
- **做可靠性 / 品质**：直接进第 5 章，FMEA 总表（§5.3.2）与量产管控（§5.5）是核心交付物，回溯链接指向前面各章的机理解释。
- **在处理真实故障**：先读第 6 章案例，看全书方法如何落到一个"高压烧机"案子上——应力缩放表（§6.2）、归因排序（§6.3）与判别实验（§6.5）可直接套用到同类问题。
- **要在单片机上落地保护与整定**：直接进第 7 章，按五层防线架构（§7.1）与 12 参数手册（§7.2）逐项实现，用 §7.6 调试路线图逐步点亮验证。
