# 快速收敛作战计划：市场返修仍在继续、客户耐心缩小时怎么打

> 由这个问题驱动："市场返修还在继续，客户耐心在缩小，如何快速收敛"。本文是行动文档，不是分析文档——分析都在 8D（第 24 篇）与附录 J/K，此处只回答"接下来 30 天每周做什么、给客户看什么、怎么把关闭时间从 8 周压到 4 周"。日期基准：2026-08-14。

## 0. 三个核心判断（先统一认知再排兵）

1. **止血与定罪是两条独立轨道**。终局路径（绕组电弧 → 热 IPM → 电容倾泻 pop）对所有起点假设共通，四层拦截（功率钳位 130 W / 三相不平衡秒停 / 上电自检拦带病重启 / IPM 提前降额）**无论根因归谁都有效**——无悔动作，不等定罪；
2. **统计口径决定客户观感**。失效集中在 ≤5 h 婴儿期 = 每个批次的风险在头几小时自耗尽，"返修还在继续"主要是持续出货+存量机陆续首用的叠加。**必须切换到按生产周分组的 cohort 失效率曲线**（横轴=批次，纵轴=该批次失效率，标注每个整改切入点）。绝对返修数在出货增长期永远难看，cohort 曲线才显示收敛；
3. **优先消灭 pop，而非总失效率**。爆响是声誉杀手；把 pop 退化成"安静地坏/拒绝启动"（自检+降额+秒停）见效最快、客户感知最强。

## 2. 两周内（至 ~8/22）——定量封口周

1. **P4 固件正式版量产切入**（IPM 提前降额 + 绕组软测温 + 黑匣子，原计划 8/22）；
2. **V3 湿度 A/B 温箱**出结果（8/15 到期）→ 根因链最后一环闭合或修正；
3. **5 台"良品"返修电机表磁 + L(θ) 分类**（用中驱自己在附录 K 建立的签名）→ 板侧子集定量封顶（≤22% 或更低）→ **责任划分的扯皮空间被数据关闭**；
4. **物流零成本降险**：新批次到位前，渠道调度优先把在库旧批次发往干燥/低压市场（EU/ANZ 组 9,852 台零失效），高湿高压区（SG/CN/HK）订单用切入后新批次满足；
5. 拆解 V1 补一刀：被吃线圈是否系统性为**线端首线圈**（判 du/dt 细化假设，直接影响整改焦点）。

## 3. 四周内（至 ~9 月初）——放行与关闭周

1. **P5 温箱回归**：50 °C + 265 VAC 连续运行，零失效零爆响 = 技术放行（原定 8/29）；
2. **切入批次第一个零失效数据点**进 8D Rev B；
3. **重谈关闭判据（最重要的谈判动作）**：把"市场失效率连续 8 周下降"改成**双判据**——"切入批次 ≥X 千台 × 首 5 小时 0 烧毁 + 温箱回归通过"。婴儿期特性（≤5 h）意味着按批次判可以在 2–3 周内积累判决性数据，按日历周判要拖两个月。**判据从日历切到批次，关闭时间从 8 周压到 ~4 周**。

## 4. 对存量机的诚实姿态（别许做不到的诺）

- 已售出机器无法刷新固件（无 OTA），0.127% 也不构成召回门槛。诚实策略：**婴儿期自耗尽 + 切入点隔离 + 售后无条件快速换新**（换新机=新批次=带全部整改）；
- 给客户的书面承诺全部锚定"切入批次之后"，不为存量机打保票——一次守不住的承诺比十次坏消息更耗耐心；
- 换回的每台失效机按三表协议（电测普查+表磁+L(θ)）入库归档——存量机的失效在数据上是资产，不只是损失。

## 5. 会议纪律（耐心管理的软件）

1. **每周五 Rev 雷打不动**——断更一次，此前积累的信任清零；
2. 会上不辩论根因归属，**让签名分类表说话**（8D D4.3 + 附录 K.3.2）；供应商整改（槽绝缘/耐压全检）无论归属都必须做，先做后争；
3. 每次会议只带三样东西：cohort 曲线（收敛证据）、行动清单燃尽（执行证据）、下周承诺（且必须守住）。
