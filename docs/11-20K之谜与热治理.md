# 第 11 章 "20 K 之谜"与热治理：损耗拆解计算与温度闭环控制

> 本章回答四个连环问题：**①** 低压端与高压端为什么热平衡温度差 ~20 K？**②** 这 20 K 能不能从基本物理/电路功率算出来？**③** 120→140 W 之间效率骤降，如何度量和拆解"哪些瓦在做功、哪些瓦在发热"？**④** 在"必须到 110 krpm、全功率 130 W+"的硬约束下，软件还有什么办法把热和温度摁住？
>
> 先立一个基准事实（来自 PQ 数据，第 8 章 §8.3）：**低压端和高压端都跑在同样的 110 krpm、同样的风道上**——气动输出完全相同。所以两端的功率差、温度差，100% 来自损耗差。这让整个分析变得干净。

---

## 11.1 20 K 从哪来：一条能闭合的计算链

### 11.1.1 第一步：多出来的瓦数（实测锚点）

同转速下整机输入功率：100 V ≈ 90 W（自由风）/ ≈120 W（装机背压）；230 V ≈ 115 W / ≈142 W；265 V ≈ 123 W / ≈152 W。**装机工况下高压端多耗 ≈20–25 W，气动输出分毫未增——这些瓦全是热。**

### 11.1.2 第二步：这些瓦的物理来源（可计算部分）

同转速、同转矩 → **基波电流两端基本相同**（约 0.75–0.85 A rms [估计值]）→ 基波铜损两端相同。多出的损耗全部来自"斩波质量"，逐项估算（$U_{dc}$：141 vs 325 V；$L$ 相瞬态电感 ≈0.6–0.9 mH；$f_{PWM}$=48 kHz [估计值]，$T_s$=20.8 μs）：

**(a) PWM 电流纹波**——主项。开关周期内绕组承受的伏秒失衡近似为：

$$\Delta I_{pp}\sim \frac{k\,U_{dc}\,T_s}{L},\quad k=f(m)\ \text{在低调制比时显著变大}$$

代入：低压端（$m\approx0.9$）$\Delta I_{pp}\approx$ 0.1–0.2 A；高压端（$m\approx0.4$）$\Delta I_{pp}\approx$ **0.5–1.0 A [估计值]**——纹波幅值放大 5–8 倍，纹波有效值约 0.15–0.29 A。它产生三处热：

| 去向 | 机理 | 量级估计（高压端）|
|---|---|---|
| 绕组交流铜损 | 纹波 RMS² × R ×（邻近效应系数 ~1.5–2 @48 kHz）| ~1–2 W |
| **定子高频铁损** | 48 kHz 次级磁滞回环；0.2 mm 冲片在此频率损耗系数极高 | ~4–8 W [估计值] |
| **磁体/转子涡流** | 烧结 42SH 磁环是导体（§8.7），直面纹波磁势 | ~3–6 W [估计值]，且全落在最怕热、最难散热的转子上 |

**(b) 死区谐波**：失真占比 9%→20%（第 6 章 §6.2 #4），5/7 次谐波电流的铜损+转子损 ~1–3 W；

**(c) 驱动板开关损耗**：$E_{sw}\propto U_{dc}\times I$，高压端 ×2.3 → 板上多 ~4–8 W（在板不在马达，但同壳共热）。

合计：**马达侧多 ~10–18 W，板侧多 ~4–8 W** ——与实测的 20–25 W 对上了。

### 11.1.3 第三步：瓦变成度（闭合）

从你的实测反推等效热阻：$R_{th}\approx\dfrac{20\ \mathrm{K}}{15\ \mathrm{W}}\approx1.3$ K/W。于是：

$$\Delta T = R_{th}\times\Delta P_{motor}\approx 1.3\times(12\sim18)\approx\mathbf{16\sim23\ K}\ \checkmark$$

**账闭合了：高压端的 20 K = 纹波物理（∝ $U_{dc}$）产生的 12–18 W 马达侧额外损耗 × 1.3 K/W 热阻。** 这就是"从基本物理电路算出来"的完整链条——每一环都可以被 §11.2 的实验单独校核。低压端没有这 20 K，只因为 $U_{dc}$ 小 2.3 倍、纹波小一个量级。

## 11.2 实测拆账：三个软件就能做的损耗分离实验

不需要昂贵的功率分析仪，用固件自己的可调参数做受控对比：

| 实验 | 做法 | 分离出什么 |
|---|---|---|
| **$f_{PWM}$ 扫频法（本章推荐首选）** | 高压端恒转速，$f_{PWM}$ 依次 32/48/64/96 kHz，记录输入功率 | 纹波损耗 ∝ $1/f_{PWM}^2$（随频率升而降）、开关损耗 ∝ $f_{PWM}$（随频率升而升）——**功率-频率曲线的下降段斜率就是马达纹波损耗的账，上升段斜率就是板损的账**，曲线最低点顺便告诉你最优 $f_{PWM}$ |
| 死区补偿 A/B | 同工况开/关补偿，记录输入功率与电流 THD | 死区谐波损耗的账（预期 1–3 W + THD 显著变化）|
| 母线功率 vs 墙功率 | $U_{dc}\times I_{dc}$（板内测）与墙上功率计对比 | 整流前端损耗的账；剩余差额即逆变+马达 |

配合两端温度饱和实验（第 10 章 E-A/E-B），四本账（基波铜损/纹波马达损/板损/前端损）全部对清。**效率的正确度量**也随之明确：分子用气动功率（同转速同风道 = 常数，PQ 报表效率列 100 V 约 28% → 230 V 约 22%），分母分档记账——你感觉到的"120→140 W 效率骤降"，本质是**分子不动、分母全涨在损耗上，边际效率 0%**。

## 11.3 软件热治理：在"必须 110 krpm"约束下摁住温度

硬约束确认：110 krpm 必须达到，装机全功率 130 W+。**软件不能减少气动功率（那是产品力），但能做三件事：削损耗、管瞬态、稳温度。**

### 11.3.1 削损耗（治本，回收 5–15 W）

1. **$f_{PWM}$ 随母线调度**：高压端 48→64/96 kHz，纹波损 ∝$1/f^2$ 陡降——按 §11.1.2 估计可回收马达侧 5–10 W，代价板损 +2–3 W（净赚，且热从最怕热的转子移到好散热的板上）。扫频实验直接给出最优点；
2. **死区补偿**（第 7 章 P7）：回收 1–3 W，同时救观测器角度精度；
3. **电流环 $U_{dc}$ 归一 + EEMF 观测器**（P3/P9）：消除高压端可能存在的隐性"虚耗电流"；
4. （评估后放弃项：MTPA——本机凸极比 2.1 但电流水平低，注入 $i_d$ 的铜损超过磁阻转矩收益，净亏，不做。）

### 11.3.2 温度闭环功率整形（Thermal Governor）——本章核心方案

不要用"一刀切限功率"牺牲 110 krpm 指标，改成**以温度为闭环变量的动态功率上限**——逻辑与手机 SoC 的 PL2 爆发/PL1 持续完全同构：

```c
/* 100 ms 周期, 接在第7章热模型之后 */
#define T_KNEE   95.0f    /* 开始介入 */
#define T_HOLD  105.0f    /* 平台温度: 红线115留10K控制余量 */
if (Tcu_est < T_KNEE)
    P_lim = P_FULL;                       /* 冷机: 满血 140W/110krpm */
else                                       /* 热了: PI 稳温, 温度不过 T_HOLD */
    P_lim = P_FULL - Kp_g*(Tcu_est - T_KNEE) - Ki_g*integ(Tcu_est - T_HOLD);
P_lim = clamp(P_lim, P_FLOOR, P_FULL);     /* P_FLOOR≈100W 保基本体验 */
/* 磁体温度计(§9.3.2)作第二路输入, 两者取最严 */
```

为什么它能同时满足"性能"与"生存"——**时间常数站在你这边**：

- 电机热时间常数 τ ≈ 2–4 min [估计值，E1 实验标定]；冷机从 25 °C 升到 95 °C 需约 1.5τ ≈ **3–6 分钟**；
- 典型吹发一次 5–8 分钟：**前 80% 时间满血 110 krpm/140 W，只有长会话的尾段被轻微整形**；
- 整形的方式是微降转速：$P\propto\omega^3$ → **转速 −5%（110→104.5 krpm）= 功率 −14%（140→120 W）**，风量只降 ~5%、用户几乎无感，换来温度平台稳稳停在 105 °C；
- 45 °C 高温环境下 governor 自动提前介入——这正是你想要的"不让它冲那么高"：**温度永远不越线，性能只在必要时、以最小代价让步**。

### 11.3.3 配套三件套

- **会话热预算**：I²t 式积分（P10/S10）兜住热模型失准的极端情形；
- **关机吹扫**：停机后 3–5 s 低速冷风，压平"热浸"峰值（停转瞬间对流消失，磁体/油脂反而冲最高温）；
- **趋势档案**（§9.4）：governor 介入时长逐月变长 = 散热在老化（尘堵/轴承），提前保养预警。

## 11.4 本章结论表

| 你的问题 | 答案 |
|---|---|
| 20 K 差异为什么存在 | 同转速同风量下，高压端多 12–18 W 马达侧纯损耗（纹波铜损+高频铁损+磁体涡流+死区谐波），×1.3 K/W 热阻 = 16–23 K ✓ |
| 能算出来吗 | 能。计算链：$\Delta I\propto U_{dc}/(Lf_{PWM})$ → 分项损耗 → ×$R_{th}$ → ΔT，本章 §11.1 全程展开，每环可实验校核 |
| 效率怎么度量拆解 | 分子=气动功率（同转速恒定），分母分四本账；$f_{PWM}$ 扫频法+死区 A/B+母线/墙功率对比，纯软件即可拆账；120→140 W 的边际效率为 0% |
| 软件怎么摁住温度 | 削损耗（$f_{PWM}$ 调度回收 5–10 W、死区补偿）+ **温度闭环功率整形**（冷机满血 110 krpm，热态 PI 稳在 105 °C 平台，靠 −5% 转速换 −14% 功率）+ 关机吹扫与热预算兜底 |
