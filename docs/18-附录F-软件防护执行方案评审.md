# 附录 F 软件防护执行方案评审（2026-07 执行表）

> 评审对象：三方案执行表——①相电流不平衡（苏闯，已完成）②超功率降转速（范路阳，7/28）③I²t（张飞，7/28），均计划 0729 下厂 100 台验证。总评：**骨架正确、执行力强**（数据驱动门限 + 正常机群误报验证 + 责任人时间线明确），本附录给出下厂前必改的三处小改动与共同缺失的横向环节。

## F.1 逐方案评审

### 方案 1 相电流不平衡

| | 内容 |
|---|---|
| 做得对 | 故障样机定门限 + 100 台正常机验证误报率，两条腿齐全 |
| **必改** | **峰峰值→整电周期 RMS（或基波幅值）三相比对**：峰值对高压端纹波（可达基波 30–50%）与毛刺最敏感，误报将在高压端集中出现；至少改 8 周期峰值平均 |
| 门限方法 | 健康 100 台分布 P99×1.3 与故障样机最小值取中点；两分布若重叠=指标区分度不足，必须换 RMS |
| 要补 | 动作分级（轻度记录+降额/重度停机）；停机后冷却计时+3 次锁存禁止热重启；**故障码与数据上电不可覆盖**（确认 0728 数据记录功能满足）；二期加上电静止 R 对称自检（更早拦截）|

### 方案 2 超功率降转速

| | 内容 |
|---|---|
| 做得对 | 降 5k 设计精准：110k→105k 按 $P\propto\omega^3$ 即 −13%（140→122 W）|
| **必改①** | 功率公式补 **3/2 系数**：$P=1.5(u_qi_q+u_di_d)$（幅值不变约定）；若标定已吸收须团队知情，并统一"墙功率 vs 电机输入"定义 |
| **必改②** | 备注"不同电压误差多少"的答案：$u_q/u_d$ 是重构值，无死区补偿时高压端系统偏差最高 ~10% → 分电压段标定或先开死区补偿 |
| 门限建议 | 稳态触发 **130 W**（=142−5% 标定误差−动态超调余量）、迟滞 ±3 W、瞬态 140 W ≤5 s（交 I²t 兜）|
| 要补 | **降 5k 不够怎么办**：本机越堵越费电（+28 W，§8.3），全堵时降 5k 仍可能超——降速无效持续 10 s 必须升级停机 |

### 方案 3 I²t

| | 内容 |
|---|---|
| 做得对 | 0728 的 8–13 万转温度曲线是**热模型标定（E1）数据**，一鱼两吃：既定 Q 门限又拟合 τ |
| **必改** | **Q=I²t 换成带散热项的一阶热状态**（会议头号技术冲突至今未修）：$x_{k+1}=x_k+\tfrac{\Delta t}{\tau}[(I/I_{cont})^2-x_k]$，τ≈150 s 初值（用 0728 曲线到 63% 温升的时间拟合）、$I_{cont}$≈0.75 A rms。纯累计 Q 的两个致命行为：略低于门限持续发热永不触发；停机后热量记忆错误 |
| 提醒 | 电流误差经平方放大（4%→Q 误差 8%）→ 增益标定值得做；"基值电流"与 $I_{cont}$ 统一为同一个数 |
| 顺手收益 | 0729 上下限电阻个体的温度曲线 → 同时验证电阻反演温度精度（第 9 章温度计的标定数据）|

## F.2 三方案共同缺失的横向环节

1. **仲裁器**：三座孤岛=会议批评的"策略互斥"重演。三方案各输出"建议功率上限/停机请求"，仲裁器取最严执行（`ref-impl/prot_fsm.c` 结构，几十行）；
2. **死区补偿不在计划**：同时决定方案 2 功率精度、方案 3 电流精度、未来测 R/温度可行性——插为 0 号任务或确认凌鸥库已开（E.7 六问）；
3. **验证测两个率**：100 台正常机=误报率 ✓；漏报率靠故障注入（不平衡样机 ✓ / 方案 2 堵风 / 方案 3 高压长跑）各真实触发一次并归档触发值与响应时间；
4. **温度直接保护缺位**：三方案全是间接量；方案 3 换正确公式后+电阻锚定即升级为 105/115 °C 温度红线（二期）。

## F.3 下厂前三件事（一句话版）

**方案 1 换 RMS 指标、方案 2 确认 3/2 系数并定 130 W 门限、方案 3 换带散热项公式**——三处都是小改动，决定第一版是长在正确骨架上还是上线后返工。
