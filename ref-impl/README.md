# motor_guard 参考实现：集成指南与可实现性评价

可编译、已自测的电机安全防护参考实现，对应全书第 7/9/11 章设计与附录 B 的会议待办。
**不是伪代码**——桌面仿真 15/15 断言通过，且仿真复现了实测现象（高压端 112 °C / 低压端 91 °C / 温差 21 K）。

## 2. 仿真验证结果（对象机 = 案例机实测参数）

| 场景 | 结果 | 意义 |
|---|---|---|
| A 高压 140 W 无防护 | 稳态 **111.8 °C**（实测参照 110–120）；低压 120 W 对照 **91.0 °C**（参照 90–100）| 仿真"真实电机"复现了现场温度带与 21 K 温差——模型与现实对上了 |
| B 开启 Governor | 平台 **108.9 °C**、持续功率 **126.8 W**、全程无封波 | **比一刀切 120 W 上限多保住 ~7 W 性能**，且温度受控——"按温度给功率"优于"按功率猜温度" |
| C 电阻锚定 | 模型参数故意偏差 ±20%：误差 **3.3 K**（有锚定）vs 15.6 K（无）| 双通道互校有效；另定量证明**个体 R0 标定必要性**（+5% 电阻公差若不标定 = +13 K 幻影温度）|
| D 上电自检 | 健康→放行；单角 +5%→降额；+15%→禁止启动 | 电流闭环注入对母线电压不敏感——150 机型高压过流教训的正解 |
| E 黑匣子 | 过流→封波→现场冻结→重新上电不覆盖→售后导出→显式清除 | 会议暴露的"上电即覆盖"漏洞被修复并验证 |

## 3. 集成方式（宿主固件需要做的全部事情）

1. 实现 `mg_port_t` 六个原语：锁定矢量注入（即 I/F 启动已有的原语）、释放、flash 页读/写/擦、毫秒时基；
2. 三个周期调用：`mg_task_fast()`（电流环周期或 1 kHz）、`mg_task_100ms()`、`mg_task_1s()`；
3. 读 `mg_outputs()`：`p_limit_w` 接速度环外层钳位、`iq_limit_amp` 接电流指令钳位、`run_permitted=false` 时封波；
4. 上电流程：`mg_bb_fault_frozen()` 检查 →（售后模式则导出）→ `mg_selftest_start/step` → 通过后 `mg_bb_log_boot()` → 正常启动；
5. 产线 EOL：把个体实测 `r_phase_25c`、`ke_25c` 写入配置区（场景 C 证明了必要性）。

资源预算：RAM ≈1.1 KB（双环形缓冲 896 B + 上下文），flash 代码段 ≈6–8 KB，
另需 2 个数据页（各 ≥1 KB）；CPU：慢任务浮点集中，M0@48 MHz 占用 <1%；快任务无除法无循环。

## 4. 可实现性评价（诚实版）

| 模块 | 落地概率 | 前置依赖 | 主要风险 | 降级路径 |
|---|---|---|---|---|
| 热模型+锚定 | **高（95%）** | 电阻辨识来源（停机瞬间法最易）；E1 实验标定 4 个热参数 | 参数标错→保护过松/过严（锚定通道可兜住漂移，见场景 C）| 先用最差散热参数保守上线，实验后放宽 |
| Governor | **高（95%）** | 热模型；速度环有外层功率/iq 钳位接口 | 与既有档位逻辑的交互（用户切档 vs 整形）需产品定义 | 先只做"降额不升档"，交互后补 |
| 上电自检 | **中高（80%）** | `apply_locked_vector` 原语（I/F 启动已有）；死区补偿开启（否则 ud 重构偏差 ~0.5–1 V，对 1.8 V 信号是 30–50% 误差——**这是本模块最大风险**）| 无死区补偿时 R 估计偏差大 | 双电流点差分法（0.2 A/0.4 A 两点斜率）消掉固定偏差，代码留有接口 |
| 黑匣子 | **高（90%）** | 2 个 flash 页；售后工具串口协议 | flash 擦写与电机中断的时序冲突（写入放在封波后执行即可）| 缩小快环缓冲；仅存慢环 |
| 保护状态机 | **高（95%）** | 各判据输入（多数已有）| 与现有"互斥策略"代码的迁移——建议整体替换而非缝合 | 分两步：先并行监测只记录不动作，对拍一周后切换执行权 |
| **整体** | **一个固件迭代周期（2–4 周）可上线 P0 集**：热模型+Governor+黑匣子+状态机；自检 v2 随后 | 需要贵方源码做真正集成与 MCU 适配 | 见下 | — |

## 5. 边界与声明

- 桌面仿真验证的是**算法逻辑与数值行为**，不是硬件时序——上机后必须走第 7 章 §7.6 的故障注入验证流程；
- 热参数默认值由实测温度反推（[E1] 标注），28/29 日热电偶实验后替换；
- 目标平台为 M0 级；峰岹 FU68xx（8051 核）需把 100ms/1s 任务改 Q15 定点，接口不变；
- `p_hf_hiline`（高压端纹波附加损耗）建议用 §11.2 的 fPWM 扫频实验标定后精化。
