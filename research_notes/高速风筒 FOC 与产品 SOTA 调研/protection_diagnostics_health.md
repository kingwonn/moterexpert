## 1. Functional safety baseline: IEC 60730-1 Annex H / IEC 60335-1 Annex R Class B software for motor-control MCUs; vendor self-test libraries; required behaviour on MCU fault

### Takeaway
Class B (or its post-2010 Annex R Table R.1 equivalent) is the normal appliance baseline whenever software is what keeps an abnormal condition (locked rotor, lost phase, over-current, over-temperature) from becoming a hazard; every major MCU vendor ships a self-test library (CPU registers, program counter, clock, flash CRC, RAM march, watchdog), and at least ST's is UL-certified for Cortex-M0+ parts with per-step run-time costs in the tens of microseconds to under 1 ms. The alternative route — keep the safety-relevant protection in hardware that does not depend on the MCU so the software burden shrinks — is commercially offered and UL-reported (Power Integrations BridgeSwitch), and is architecturally the same idea as the team's existing 6 A hardware comparator trip.

### Cited Findings

**Standard structure and classification**
- Annex H of IEC 60730-1 classifies control software into Class A, B and C; vendor "Class B" libraries implement the self-test measures for the Class B tier (Microchip AN1229, undated in snippet) — [Microchip AN1229 (TCNJ mirror)](https://owd.tcnj.edu/~hernande/ELC343/01229A.pdf)
- Table H.11.12.7 of Annex H lists the MCU components that must be tested, the faults to be detected and acceptable measures; which components apply depends on the software class; some tests an end application needs are not in the table at all (Infineon PSoC 6 Class B library guide) — [Infineon PSoC 6 IEC 60730 Class B library](https://documentation.infineon.com/psoc6/docs/bru1727171411239)
- Typical library test items: CPU registers (stuck-at), program counter (jump to wrong address), program-flow check; invariable memory (flash CRC) and variable memory (RAM) tests. One Renesas note maps its flash test to "H.2.19.4.1 CRC – single word" and its RAM test to "H.2.18.10.1" (which Renesas note: attribution unverified) — [Infineon PSoC 6](https://documentation.infineon.com/psoc6/docs/bru1727171411239); [Renesas RL78 IEC 60730/60335 self-test library](https://www.renesas.com/us/en/document/apn/iec6073060335-self-test-library-ccrl78-rl78-mcu-application-notes)
- Class definitions as summarised in vendor material: Class A — safety does not rely on software; Class B — software prevents unsafe operation; Class C — software prevents special hazards. Class B is described as the class most commonly used for household appliances — [Electronic Design, "Motor control for appliance safety standards"](https://www.electronicdesign.com/technologies/industrial/motion-control/article/21194957/motor-control-for-appliance-safety-standards); [Power Integrations white paper W006](https://www.power.com/sites/default/files/documents/pi_whitepaper_w006_simplified_product_safety_certification_through_hardware_based_motor_fault_protection_with_bridgeswitch.pdf)
- IEC 60335-1 (2001 edition text, after A1:2004 added Annex R): "If failure of the software in the presence of another fault in the appliance would result in a hazard, then software class B shall be used. If failure of software alone would result in a hazard, then software class C shall be used." — [IEC 60335-1:2001 sample (iTeh)](https://cdn.standards.iteh.ai/samples/10565/75257731047840649fa9c8b822d98e00/IEC-60335-1-2001.pdf); [IEC 60335-1:2001/AMD1:2004 abstract](https://standards.iteh.ai/catalog/standards/iec/d616da51-b90e-421e-b6a6-9b919c6dac6f/iec-60335-1-2001-amd1-2004)
- IEC 60335-1 (2006 consolidated Ed. 4.2): compliance is checked by evaluating the software against Annex R; if software is changed, the evaluation and relevant tests must be repeated where the change could affect the results of tests involving protective electronic circuits — [IEC webstore preview Ed. 4.2](https://webstore.iec.ch/p-preview/info_iec60335-1%7Bed4.2%7Db.pdf)
- A later revision of IEC 60335-1 "introduced a revamped normative Annex R software evaluation and deleted software Class B and Class C" (wording from an Indian BIS adoption document; the snippet does not say which edition made the change). IEC 60335-1:2020 (Ed. 6.0) retains Annex R as a normative annex — [BIS adoption document](https://services.bis.gov.in/tmp/1733901588.pdf); [IEC 60335-1 Ed. 6.0 preview (VDE)](https://www.vde-verlag.de/iec-normen/preview-pdf/info_iec60335-1{ed6.0}en.pdf)
- Programmable electronic circuits that need software to control fault conditions for IEC 60335-1 compliance also have to meet Annex H of IEC 60730-1; the white paper calls this "a time consuming and costly process" (Power Integrations, vendor view) — [PI white paper W006](https://www.power.com/sites/default/files/documents/pi_whitepaper_w006_simplified_product_safety_certification_through_hardware_based_motor_fault_protection_with_bridgeswitch.pdf)
- TI states IEC 60730 Class B/C and UL 1998 Class 1/2 share a similar classification definition (which TI document: attribution unverified) — [TI SPNY005](https://ti.com/lit/pdf/spny005)

**Motor-control-specific points**
- When motor speed is estimated in software from shunt-measured inverter currents (i.e. sensorless control used for a safety-relevant decision), that software must be Class B compliant, and the code must detect current-sensor faults such as an open or short circuit of the sensing element (International Rectifier-authored article; date not shown in snippet, several years old) — [Electronic Design](https://www.electronicdesign.com/technologies/industrial/motion-control/article/21194957/motor-control-for-appliance-safety-standards)
- Abnormal-operation tests that the motor protection must survive, as described by Power Integrations: the stalled-motor test (rotor locked, rated voltage applied) and, for multi-phase motors, operation with one phase disconnected — [PI white paper W006](https://www.power.com/sites/default/files/documents/pi_whitepaper_w006_simplified_product_safety_certification_through_hardware_based_motor_fault_protection_with_bridgeswitch.pdf)
- Conventional over-current sensing can miss a locked/stopped sensorless BLDC rotor because a stopped rotor can draw *less* current than a normally running one; the patented remedy briefly disables the outputs and samples back-EMF to check whether the rotor is turning (Tecumseh, US 7,042,180, granted 2006) — [US7042180](https://patents.google.com/patent/US7042180)

### Inferences
- For the team's drive, the safety-relevant functions that would fall under Annex R are the software protections (I²t, power limit, phase imbalance, stall/loss-of-sync, NTC over-temperature). The 6 A comparator trip is hardware and — if it disables the bridge without MCU involvement — is the kind of MCU-independent path the PI white paper argues simplifies certification. Whether any software function is "safety-relevant" depends on what the 60335-2-23 clause-19 tests show with that function disabled; this is a certification-lab decision, not something the sources settle.
- Cortex-M0 feasibility: **feasible** — ST's M0+ library timing (≈12 µs per RAM block, ≈0.86 ms per 17 KB flash CRC slice) shows run-time self-tests can be interleaved in a background task without touching the FOC interrupt; a 128 KB flash image would take roughly 7–8 such slices at the quoted rate (my scaling of the UM3083 figure; clock-dependent).
- The Tecumseh observation (locked sensorless rotor may draw less current than normal) means the locked-rotor abnormal test cannot be assumed to be covered by over-current/I²t alone; a dedicated stall/loss-of-sync detector (Section 4) is part of the safety argument.
- Because the Electronic Design article requires detection of an open/short current-sense element when sensorless speed is safety-relevant, a shunt/amplifier plausibility check (offset at PWM-off, sum-of-currents or bus-current consistency) belongs in the Class B measure list.

## 2. Winding fault detection in PMSM drives: inter-turn short circuit (ITSC), open phase, high-resistance connection, insulation (ground-wall) monitoring

### Takeaway
Published ITSC detectors that need no extra sensors (2nd-harmonic in dq voltages/currents/power, negative-sequence components, observer residuals) report laboratory sensitivity down to a single shorted turn (1/54 = 1.9 % in HIL; 1/102 < 1 % on a real drive), but all results are lab-scale on low-speed machines, the signature amplitude depends on current-controller bandwidth, operating point and fault resistance, and no production deployment in a consumer drive was found. Zero-sequence-voltage, PWM-ripple and search-coil methods need extra hardware; neural-network methods have so far been shown on automotive-class MCUs (AURIX TC397), not on Cortex-M0.

### Cited Findings

**Context / reviews**
- Reviews group ITSC diagnosis into model-based (state/parameter estimation: Luenberger, sliding-mode, Kalman), signal-based and AI/data-based methods; one EV-focused review (Jiang et al., World Electric Vehicle Journal, April 2024) states inter-turn short faults account for 21 % of motor faults — [WEVJ 15(4):165](https://mdpi.com/2032-6653/15/4/165); [DOAJ record](https://doaj.org/article/a7118e1467294c4ea0a9ebfb309098ff)
- A 2025 Energies review covers ITSC, partial demagnetisation and eccentricity in PM machines, classified by fault signature, with an evaluation/comparison section — [Energies 18(3):534](https://mdpi.com/1996-1073/18/3/534)
- The short-circuit circulating current "does not flow through the regular phase current sensors", which is why ITSC is hard to see with standard measurements (stated in one of the reviews returned; attribution unverified) — [White Rose 223131](https://eprints.whiterose.ac.uk/223131)
- Zafarani et al. (IEEE, 2018, "Interturn short-circuit faults in PMSMs: an extended review and comprehensive analysis"): fault signatures depend on fault intensity, operating conditions, resistance of the short-circuit path and controller action; some current-spectrum signatures are suppressed by the current controllers and their amplitude depends strongly on controller coefficients — [ResearchGate record](https://www.researchgate.net/publication/323530560_Interturn_Short-Circuit_Faults_in_Permanent_Magnet_Synchronous_Machines_An_Extended_Review_and_Comprehensive_Analysis)
- Most winding deterioration begins as an inter-turn fault in which two or more turns become short-circuited (University of Nottingham study on incipient winding faults in a PM drive) — [Nottingham repository](https://nottingham-repository.worktribe.com/OutputFile/767681)

**2nd-harmonic (2f) signatures in the synchronous frame — no extra sensors**
- Boileau, Leboeuf, Nahid-Mobarakeh, Meibody-Tabar (IEEE Trans. Power Electronics, vol. 28 no. 12, pp. 5647–5654, 2013): the magnitude of the 2nd harmonic of the *control (reference) voltages*, extracted by a time-domain transformation (synchronous demodulation), is compared with a predefined threshold; described as low-cost in CPU time — [ResearchGate record](https://www.researchgate.net/publication/260197669_Synchronous_Demodulation_of_Control_Voltages_for_Stator_Inter-turn_Fault_Detection_in_PMSM)
- Ahn et al. (IEEE SDEMPED 2019): for surface-mounted PMSMs, split the dq reference voltage into healthy and faulty parts and use the DC bias and 2f amplitude as indicators; claimed to work at low sampling rate without additional sensors; validated by simulation only — [IEEE Xplore 8864924](https://ieeexplore.ieee.org/document/8864924/); [University of Seoul record](https://pure.uos.ac.kr/en/publications/inter-turn-short-circuit-fault-detection-in-permanent-magnet-sync/)
- Hsu et al. (Int. J. Circuit Theory and Applications, 2023): 2nd-order harmonics in dq currents with an amplitude-tracking algorithm "implemented by using a common digital signal processor without complex algorithms and additional hardware or sensors"; validated by FEA and hardware-in-the-loop; detects a fault of **1 of 54 turns (1.9 %)** in one phase — [catalogue record](https://searchworks.jioinstitute.edu.in/articles/asx__164681901)
- Energies 2022 (15(9):3248): the 2nd harmonic in phase instantaneous reactive power is shown to be the characteristic feature for stator winding fault detection — [doi:10.3390/en15093248](https://doi.org/10.3390/en15093248)
- Bouzin et al. (SCEMS 2025): compared a dq-voltage-harmonic method with a negative-sequence-voltage method under closed-loop operation on a 1 kW PMSM bench; concluded the negative-sequence approach is more robust to waveform distortion — [ULB record](https://difusion.ulb.ac.be/vufind/Record/ULB-DIPOT:oai:dipot.ulb.ac.be:2013/402610/TOC)
- A 2023 paper is titled "Robust inter-turn short-circuit fault detection in PMSGs with respect to the bandwidths of current and voltage controllers", i.e. controller-bandwidth dependence of the indicator is treated as a design problem in its own right (content beyond the title not read) — [ResearchGate record](https://www.researchgate.net/publication/370621448_Robust_Inter-turn_Short-Circuit_Fault_Detection_in_PMSGs_with_Respect_to_the_Bandwidths_of_Current_and_Voltage_Controllers)

**Negative-sequence / observer-residual methods — no extra sensors**
- Hasan Ebrahimi, Choux, Huynh (Sensors 22(9):3407, 2022): structural analysis of the abc-frame PMSM model gives four structured residuals; a generalised likelihood-ratio test (GLRT) is the detector; **detects a single shorted turn out of 102 (<1 %)**; experiments on an in-house inverter-fed PMSM with 1 %, 3 % and 5 % faults switched in by relays; the method uses an encoder (it also diagnoses encoder faults). Detection time not stated in the snippets — [PMC9101979](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9101979/)
- Sliding-mode-observer "diversified diagnosis" (c. 2024): ratio of negative- to positive-sequence current rises from 0.40 to 14.18 (simulation) and from 0.52 to 19.89 (experiment) going from healthy to 7 shorted turns; the authors state the influence of current-controller bandwidth on the signature is minimised (units and total turns not given in snippet) — [ResearchGate record](https://www.researchgate.net/publication/377320375_Diversified_Diagnosis_Strategy_for_PMSM_Inter-Turn_Short-Circuit_Fault_via_Novel_Sliding_Mode_Observer)
- Reconstructed negative-sequence current + phase angle for detection and faulty-phase location (J. Electrical Engineering & Technology, 2025) — [Springer](https://link.springer.com/article/10.1007/s42835-025-02289-0)
- Two adaptive-observer solutions for interturn fault detection in IPMSMs (arXiv, May 2025) — [arXiv 2505.23125](https://arxiv.org/html/2505.23125v1)
- Patents exist on online ITSC monitoring/compensation and on estimating the number of shorted turns (US 12,255,565; US 11,843,339) — [US12255565](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/12255565); [US11843339](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/11843339)

**Zero-sequence voltage component (ZSVC) — needs neutral/voltage sensing**
- Urresty et al. (EPE 2011): ZSVC of the stator voltages detects ITSC under transient (non-stationary) conditions; a linear ZSVC-vs-speed relationship is used as a severity index; Hilbert–Huang processing — [Recercat record](https://recercat.cat/handle/2072/224433)
- Urresty, Riba, Romeral, Ortega (Electrical Engineering, 2015): ZSVC analysis allows simultaneous diagnosis of resistive unbalance and inter-turn faults, compared against stator-current-harmonic analysis; simulation and experiment — [Tecnalia record](https://scienceportal.tecnalia.com/en/publications/mixed-resistive-unbalance-and-winding-inter-turn-faults-model-of-/)
- IEEE TPEL 2015 (other authors): ZSVC-based indicators that remove the influence of rotor-speed variation, with a frequency-tracking algorithm; detects the fault and identifies the faulty phase — [record](https://manuscript.isc.ac/Inventory/49/553371.htm)

**High-frequency / PWM-ripple methods**
- Sen & Wang (IEEE Trans. Industrial Electronics, 2016): turn-fault detection from the inverter's own PWM ripple current (no injection), ripple extracted by a simple analogue band-pass + RMS circuit; extended to multiphase machines by Hu et al. (IEEE TIA 2017) — [White Rose AAM](https://eprints.whiterose.ac.uk/id/eprint/105458/8/AAM.pdf)
- HF voltage-injection method for inverter-fed PMSMs with severity expressed by short-circuit ratio and fault resistance (2023) — [AMiner record](https://www.aminer.org/pub/63ecc49c90e50fcafdf678a7/inter-turn-short-circuit-fault-detection-with-high-frequency-signal-injection-for)
- Stated drawbacks: injected HF currents add torque ripple and thermal stress; rotating HF current injection is limited to a few hundred Hz by the HF current-regulator bandwidth; PWM-ripple schemes are not usable at standstill (IEEE TTE manuscript, 2024) — [White Rose TTE 2024](https://eprints.whiterose.ac.uk/id/eprint/218143/1/TTE-Reg-2024-07-1794.pdf)
- Patent US 11,509,255: the closed-loop current controller "creates an imbalanced voltage since it counteracts the imbalanced phase inductance caused by the short circuit"; remedy is to inject a signal above the current-loop bandwidth and detect unbalanced HF current in the dq feedback — [US11509255](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/11509255)

**Machine learning**
- IECON 2023: MLP and CNN ITSC detectors deployed on an automotive **AURIX TC397**; inference and preprocessing times were measured and judged short enough; test motor is a configurable multi-phase PMSM with winding taps (numbers not in snippet) — [BUT repository](https://dspace.vut.cz/bitstreams/bbd634ee-844c-4ad6-8447-e200d95f2e1f/download); [IEEE Xplore 10312642](https://ieeexplore.ieee.org/document/10312642/)
- IET Electric Power Applications 2024: convolutional-LSTM "deep regulated" network, 20 input features, 5 fault classes, implemented in TensorFlow/Python (not embedded) — [IET EPA](https://ietresearch.onlinelibrary.wiley.com/doi/10.1049/elp2.12525)
- A Cortex-M4 implementation of spectral (MCSA) ITSC detection running alongside FOC has been published (IFAC-PapersOnLine, 2016) — [ScienceDirect](https://www.sciencedirect.com/science/article/pii/S2405896316326519)
- Model-based transfer learning for ITSC detection (Sensors, 2023) — [PMC10675758](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10675758/)

**Open-phase fault**
- IEC 60335-1-style abnormal testing of multi-phase motors includes running with one phase disconnected (per PI) — [PI white paper W006](https://www.power.com/sites/default/files/documents/pi_whitepaper_w006_simplified_product_safety_certification_through_hardware_based_motor_fault_protection_with_bridgeswitch.pdf)
- Normalised-current method (average absolute value of normalised phase currents), no extra sensors, diagnosis time ≈25–30 % of one fundamental current cycle — reported on an **induction-motor** drive (J. Operation and Automation in Power Engineering) — [JOAPE paper](https://joape.uma.ac.ir:443/article_2945_4f39b81a944ee54019916ebcfb97deed.pdf)
- With FOC and PI regulators the current references are available inside the controller, which helps reference-vs-measured open-phase criteria (statement attributed to Meinguet et al.; source page attribution unverified). ### Inferences
- **Feasibility on fixed-point Cortex-M0 with shunts only (inference from the cited method descriptions):**

| Method | Extra hardware | M0 feasibility | Remarks for 110 krpm / 1833 Hz |
|---|---|---|---|
| 2f synchronous demodulation of Vd/Vq references or of p = vd·id+vq·iq (Boileau 2013; Ahn 2019; Hsu 2023) | none | Feasible (two multiplies + low-pass per sample; no FFT) | 2f = 3667 Hz is likely near/above current-loop bandwidth, so the signature will be split between dq-current ripple and voltage commands — monitor both, or a power-based quantity |
| Negative-sequence V/I via counter-rotating frame (Bouzin 2025; SMO paper) | none | Feasible (extra Park transform at −θ + low-pass) | Same quantity the team's existing "phase imbalance" protection presumably already approximates |
| Observer-residual + GLRT (Sensors 2022) | published version uses encoder | Marginal (abc-frame model, statistics; needs accurate parameters) | Sensorless variant not demonstrated |
| ZSVC (Urresty) | neutral point + voltage sense | Not feasible without hardware change | — |
| PWM-ripple RMS (Sen & Wang) | analogue band-pass/RMS circuit + extra current sensing | Not feasible with existing BOM | — |
| HF injection | none, but adds loss/torque ripple | Marginal; injection must sit above current-loop bandwidth yet below PWM Nyquist — little room at 1.8 kHz fundamental | — |
| CNN/MLP (IECON 2023) | none | Not demonstrated below AURIX-class; unlikely worthwhile on M0 | — |

- All sub-2 % sensitivity figures come from machines with tens to ~100 turns per phase at low electrical frequency. A 130 W, 110 krpm hair-dryer stator has few turns per phase (exact count not known here), so a one-turn short is a much larger fraction of the phase than 1–2 % — which makes it easier to see but also much more destructive (induced circulating current scales with speed). No paper was found that tests ITSC detection on a ≥100 krpm appliance motor; detection thresholds must be established empirically with tapped-winding samples.
- False-alarm sources named in the literature (inherent asymmetry, waveform distortion, controller bandwidth, operating point) imply any 2f/negative-sequence indicator needs a per-unit healthy baseline. The team has EEPROM: storing an EOL baseline of the indicator at a few speed points and alarming on *change from baseline* is the natural low-cost design (consistent with the per-unit fingerprinting practice in Section 9).
- Open-phase: at ≥100 krpm one electrical cycle is 0.55 ms, so even a "multi-cycle" normalised-current detector responds within a few milliseconds; reference-vs-measured current criteria are free under FOC.
- HRC: on a shunt-sensed drive the realistic online indicator is the same negative-sequence voltage / 2f-in-dq-voltage quantity as for ITSC (resistive unbalance looks like a negative-sequence impedance); ITSC and HRC are distinguished in the literature by ZSVC angle or by speed/load dependence, which is not available without neutral sensing.
- Ground-wall monitoring methods found all need leakage/common-mode current sensing or added inverter circuitry; none is implementable with phase shunts and DC-bus voltage alone. For a Class II hand-held appliance this function is realistically covered by EOL hipot/insulation/surge tests (Section 9) rather than online monitoring.

## 3. Demagnetisation detection (flux-linkage estimation, back-EMF harmonics, inductance change) and reported sensitivity

### Takeaway
Observer/estimator-based flux-linkage tracking is the only demagnetisation indicator available without extra sensors; published accuracy is of the order of a few percent of flux linkage (≤5 % in a dual-EKF study) and a 2024 overview rates model-based flux methods as "low sensitivity", with demonstrations typically at 25–50 % uniform demagnetisation. Finer detection (≈8 %) and localisation of partial demagnetisation rely on search coils, Hall sensors or air-gap flux sensing, which this product does not have; no production implementation in consumer drives was found.

### Cited Findings
- Dual extended Kalman filter demagnetisation diagnosis (2023): experimentally, estimated dq inductances and PM flux linkage are within 5 % of reference values (an estimation-accuracy figure, not a minimum-detectable-fault figure) — [DOAJ-indexed record](https://library.kab.ac.ug/Record/doaj-art-1433ed0f1c624e069876d4fbfa7d8c32/Description)
- Cao & Wu (Machines 10(5):354, 2022): flux observer with harmonic flux amplitudes as augmented states; online detection and quantitative grading using amplitude and waveform of observed flux; simulated uniform cases were 25 % and 50 % flux reduction — [doi:10.3390/machines10050354](https://doi.org/10.3390/machines10050354)
- Search-coil residual back-EMF method (Applied Sciences 16(2):870, 2026): minimum detectable demagnetisation degree 8 %; requires search coils — [doi:10.3390/app16020870](https://doi.org/10.3390/app16020870)
- Non-singular fast terminal sliding-mode observer reconstructs PM flux linkage online for IPMSM demagnetisation detection (Sensors, 2015) — [PMC4299055](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC4299055/)
- Faiz et al. overview (IET Electric Power Applications, 2024) tabulates detection schemes by uniform vs partial fault and online vs offline, and rates model-based flux methods as "low sensitivity" — [IET EPA overview](https://ietresearch.onlinelibrary.wiley.com/doi/full/10.1049/elp2.12519)
- Variation of dq inductances and stator resistance "can cause inaccurate estimation and failure of demagnetization fault detection"; a least-squares method with bounded estimation error is proposed for EV PMSMs (link attribution unverified) — [WEVJ 16(2):112](https://www.mdpi.com/2032-6653/16/2/112)
- Trailing-edge (partial) demagnetisation in surface PMSMs is hard to see in back-EMF, current, vibration or leakage flux; in a 1.8 kW experiment air-gap-flux-based detection was the most reliable (link attribution unverified) — [Univ. Oviedo repository](https://digibuo.uniovi.es/dspace/bitstream/10651/53236/1/53236.pdf)
- A back-EMF-based method for detecting magnet failures in PMSMs exists (measured/estimated back-EMF signature) — [ResearchGate record](https://www.researchgate.net/publication/230757857_A_Back-emf_Based_Method_to_Detect_Magnet_Failures_in_PMSMs)
- PM flux linkage falls with rotor temperature (reversible), which is the basis of flux-based magnet-temperature estimation and therefore a confound for demagnetisation detection — [J. Eng. 2019 (DOAJ)](https://doaj.org/article/accca5986bd04e3e88eaeb902dd7b133)
- EOL back-EMF testing is used by test-equipment vendors to expose magnet demagnetisation and winding shorts before shipment (AIP) — [AIP 艾普](https://www.aipuo.com/news/1305.html)

### Inferences
- Cortex-M0 feasibility: **feasible in a coarse form.** A sensorless-FOC flux/back-EMF observer already yields an effective ψ_PM (or Ke) estimate at steady state; a slow (seconds) fixed-point average of (vq − R·iq − ω·Ld·id)/ω at a defined operating point costs almost nothing. Its accuracy is bounded by DC-bus measurement, dead-time error and R/L uncertainty — at 110 krpm the back-EMF term dominates the voltage equation, so the R error matters little, which is favourable compared with the low-speed machines in the literature.
- Because reversible thermal flux loss and irreversible demagnetisation produce the same signature, a practical detector compares ψ_PM at a *reference thermal state* (e.g. the first seconds after a cold start, judged from NTC) against the per-unit EOL value stored in EEPROM. With ≤5 % estimator accuracy as the literature benchmark, a realistic alarm threshold is in the ≥8–10 % range (inference; no source demonstrates this on an appliance drive).
- A 2-pole rotor (single diametrically magnetised or ring magnet) makes "partial demagnetisation of one pole" signatures (fractional harmonics in back-EMF) largely inapplicable; uniform loss is the relevant mode. No source addressed 2-pole high-speed rotors specifically.

### Gaps
- No source gave a minimum detectable uniform demagnetisation (e.g. 5 % / 10 %) for a purely observer-based, sensorless method.
- Inductance-change-based and HF-injection-based demagnetisation detection sensitivity: not found.
- No data on demagnetisation incidence or detection in ≥100 krpm hair-dryer/vacuum motors was found.

## 4. Loss-of-synchronisation / stall detection in sensorless FOC, and blocked-airflow / clogged-filter detection via power–speed relationships

### Takeaway
Production sensorless-FOC ICs implement stall protection as a small set of plausibility checks — abnormal speed, abnormal back-EMF (estimated vs expected back-EMF), no-motor/loss-of-sync — with configurable latch-or-retry response; patents add Vq-consistency and observer-error criteria that need no extra parameters. Blocked-inlet/filter detection from motor speed (or speed deviation at a given drive level) and from motor power is established in the patent literature for vacuums, hand dryers and pumps; no quantitative sensitivity data were found.

### Cited Findings
- Loss of synchronisation between rotor and stator fields causes the motor to stall (Microchip AN2590; AN1292 PLL-estimator note) — [Microchip online docs](https://onlinedocs.microchip.com/oxy/GUID-94F279C6-1342-4E97-B4A0-AEBFA48CEF3D-en-US-3/GUID-ACE5CF67-F2B3-4C37-B172-C59BF4475CBB.html); [Microchip AN1292](https://www.microchip.com/content/dam/mchp/documents/OTH/ApplicationNotes/ApplicationNotes/01292A.pdf)
- A mechanical block or stall may not be recognised by the sensorless algorithm on its own; US 10,075,107 B2 compares a back-EMF observer error against a threshold that depends on estimated rotor angular frequency — [US10075107](https://patents.google.com/patent/US10075107)
- US 11,387,756 B1: compares applied q-axis voltage against thresholds derived from an estimated Vq; claims detection of stalls during "wobbling" and inaccurate sensorless frequency lock; does not use motor inductance; debounce logic for start-up and fast transients — [US11387756](https://patents.google.com/patent/US11387756)
- US 11,728,753: declares stall/loss-of-sync and stops the motor when speed fails to reach the open-loop-to-closed-loop switch-over threshold within a set period — [US11728753](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/11728753)
- At standstill the back-EMF carries no position information (NXP AN4935) — [NXP AN4935](https://www.NXP.com/docs/en/application-note/AN4935.pdf)
- A locked sensorless BLDC rotor can draw less current than a running one, so over-current alone does not cover locked rotor (Tecumseh, US 7,042,180) — [US7042180](https://patents.google.com/patent/US7042180)
- TI MCF8316A (production sensorless-FOC driver; datasheet SLLSFI0C, Aug 2021, rev. - Filter-replacement reminder (US 11,950,753, Chinese-origin, brushed or brushless motors): filter is deemed blocked when the rotating-speed difference is ≥ a preset threshold — [US11950753](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/11950753)
- Pump safety vacuum-release (US 10,724,263 B2): inlet obstruction detected from a measurement related to motor power consumption — [US10724263B2](https://patents.google.com/patent/US10724263B2/en)
- Hand dryer with brushless motor (US 9,267,736 B2 / EP 2764168 B1): a filter sensor reads intake vacuum; at high vacuum the controller shuts down and disables the motor — [US9267736](https://patents.google.com/patent/US9267736)
- Hair-dryer-specific prior art: Conair clogged-filter alarm (US 5,325,809, 1993, mechanical) and a hair dryer with reverse-blowing dust removal (US 12,383,040) — [US5325809](https://patents.google.com/patent/US5325809); [US12383040](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/12383040)
- Hair-dryer safety testing includes blocked air inlet or outlet and motor locked-rotor as abnormal-operation conditions (Chinese test-lab summaries of GB 4706.15) — [CTNT 中为检验](https://www.ctnt-cert.com/xwgg/28617.html); [Sohu explainer](https://m.sohu.com/a/954168872_121327213/?pvid=000115_3w_a&scm=10001.8085_13-8085_13.0.0-0-0-0-0.0)

### Inferences
- Cortex-M0 feasibility: **all three production-style checks are feasible** (compare |E_est| with Ke·ω_est; speed-command tracking error; current-present check) — each is a compare-and-debounce on quantities the FOC loop already computes. The Vq-consistency check of US 11,387,756 is equally cheap.
- For a fan load, shaft power follows a fixed curve versus speed for a given flow restriction. With a centrifugal/mixed-flow impeller a blocked inlet reduces mass flow and therefore *reduces* shaft power at a given speed (or raises speed at a given power) — the same physical relationship the vacuum patents exploit ("speed is indicative of load"). The drive already computes electrical power for its power limit, so a P(ω) "healthy band" check stored per unit at EOL is implementable without new hardware. Direction and magnitude of the shift for this specific impeller must be measured; no source quantified it.
- A blocked inlet also removes the motor's and heater's cooling air; blocked-airflow detection is therefore the missing input that a plain I²t model lacks (see Section 5).
- Policy inference from the TI IC's option set: latch-until-power-cycle for abnormal-BEMF/loss-of-sync, limited auto-retry for start-up failures, is the range of behaviours a production controller exposes; which one is acceptable in clause-19 tests is a product decision.

### Gaps
- No quantitative sensitivity (e.g. % inlet blockage detectable, detection time) was found for power–speed blockage detection in hair dryers or vacuums.
- ST MCSDK speed-feedback-reliability logic and Infineon iMOTION rotor-lock/"PLL out of control" criteria: query not executed (budget).
- Whether leading high-speed hair dryers (Dyson, Laifen, Dreame, etc.) implement inlet-blockage detection electrically was not found.

## 5. Sensorless thermal protection: I²t vs lumped-parameter thermal networks, resistance-based winding temperature estimation, flux-based magnet temperature estimation, sensor fusion; accuracy and ambient handling; commercial implementations

### Takeaway
Published sensorless winding-temperature accuracy clusters around ±2–6 K for DC/d-axis-injection resistance tracking in lab PMSM tests (up to ±10 °C on a traction induction machine) and about 5–8 K worst-case for low-order (2–4 node) lumped-parameter thermal networks on automotive machines; hybrids of the two (thermal model corrected by an electrical-parameter observer) are the academic state of the art. No commercial appliance-drive implementation and no result for a ≥100 krpm air-cooled motor were found.

### Cited Findings

**Framework**
- Wallscheid, "Thermal Monitoring of Electric Motors: State-of-the-Art Review and Future Challenges" (IEEE Open Journal of Industry Applications, vol. 2, pp. 204–223, 2021): splits methods into indirect ones that track temperature-sensitive electrical parameters and direct thermal models such as LPTNs — [Paderborn RIS](https://ris.uni-paderborn.de/record/29664); [DOAJ record](https://doaj.org/article/54814ae2d94646918eb555ea881ac5ea)
- Indirect electrical-parameter methods are sensitive to model parameters: inaccurate modelling, even within manufacturing tolerances, can produce large estimation errors; LPTNs trade physical fidelity for real-time speed and need substantial expert effort to design (Kirchgässner, Wallscheid, Böcker, 2020) — [arXiv 2001.06246](https://arxiv.org/pdf/2001.06246.pdf)
- A 2025 review of rotor-temperature estimation groups methods into physics-based thermal models, observer/identification-based approaches and data-driven ML — [Applied Thermal Engineering review](https://www.sciencedirect.com/science/article/abs/pii/S135943112503683X)
- An MDPI Electronics review (vol. 15 no. 6, art. 1249) covers online PMSM temperature estimation for EVs: thermal-model, electrical-model and data-driven classes — [Electronics 15(6):1249](https://www.mdpi.com/2079-9292/15/6/1249)

**Lumped-parameter thermal networks (LPTN)**
- Wallscheid & Böcker (c. 2015): four-node LPTN (stator yoke, stator winding, stator teeth, permanent magnets) globally identified from measurements; worst-case error 8 °C over all modelled temperatures, cross-validated on independent load profiles — [ResearchGate record](https://www.researchgate.net/publication/282332970_Global_Identification_of_a_Low-Order_Lumped-Parameter_Thermal_Network_for_Permanent_Magnet_Synchronous_Motors)
- IEEE (2025): analytically solvable LPTN for real-time stator hot-spot estimation, suitable for automotive-grade microcontrollers; residual estimation error ≈5 °C on a traction PMSM — [IEEE Xplore 11030560](https://ieeexplore.ieee.org/document/11030560/)
- Linköping University thesis (2023): two-node LPTN (winding, magnets) for a water-cooled IPMSM; estimated winding temperature deviated from measurement by at most 5 °C — [DiVA full text](https://liu.diva-portal.org/smash/get/diva2:1790319/FULLTEXT01.pdf)
- IET Electric Power Applications 2023: 3-node LPTN assisted by a (static) winding sensor limits maximum rotor-temperature error to <1 °C (not sensorless) — [IET EPA](https://ietresearch.onlinelibrary.wiley.com/doi/full/10.1049/elp2.12296)
- Thermal Neural Networks (Kirchgässner, Wallscheid, Böcker, 2021): LPTN-structured neural model reports an error of 5.84 K with 64 model parameters (metric type — worst-case vs RMS — to be confirmed in the paper) — [arXiv 2103.16323](https://arxiv.org/pdf/2103.16323v1)
- OLTEM lumped-thermal + deep-neural hybrid (AI 6(8):173, 2025): maximum absolute error ≈4.3–8.2 °C — [doi:10.3390/ai6080173](https://doi.org/10.3390/ai6080173)

**Resistance-based winding temperature (signal injection)**
- Principle and trade-off (US 8,866,428): DC resistance = DC voltage component / DC current component, temperature from the copper temperature coefficient; larger injected DC current improves accuracy but increases torque oscillation; because thermal time constants are seconds to minutes the estimate can be run slowly/intermittently — [US8866428](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/8866428)
- Wilson, Stewart, Taylor (IEEE Trans. Energy Conversion, 2010): "fixed angle" and "fixed magnitude" current-injection techniques with "unipolar"/"bipolar" separation of injected and motoring signals; reported to work under load without disturbing torque or speed — [White Rose 152538](https://eprints.whiterose.ac.uk/152538)
- Energies 11(8):2033 (2018): d-axis current injection of −1 A with an FEA-derived look-up table; maximum winding-temperature estimation error ≈2 °C — [doi:10.3390/en11082033](https://doi.org/10.3390/en11082033)
- IET Electric Power Applications (2019): dual DC-current injection with Kalman filter for a dual three-phase PMSM; maximum error ≤3 °C — [IET EPA 2019](https://ietresearch.onlinelibrary.wiley.com/doi/full/10.1049/iet-epa.2019.0049)
- Dual three-phase PMSM, simultaneous winding and magnet temperature by current injection (c. 2021): maximum error 6 °C (winding) and 3 °C (magnet); dead-time effect cancelled by the dual-set structure — [ResearchGate record](https://www.researchgate.net/publication/352669031_Current_Injection-Based_Simultaneous_Stator_Winding_and_PM_Temperature_Estimation_for_Dual_Three-Phase_PMSMs)
- Applied Sciences 12(17):8812 (2022): "double dead-time" DC injection on a railway-traction induction machine cancels inverter non-linearity; temperature error kept within ±10 °C; inverter dead-time is called "an important drawback in DC injection strategies" — [doi:10.3390/app12178812](https://doi.org/10.3390/app12178812)
- A DC-injection thermal-protection study on a 4.5 kW machine stresses that accurate estimation of the injected DC voltage requires careful compensation of inverter non-idealities (the search summary called it a PMSM; the linked record's title is a vector-controlled induction-motor drive — attribution unverified) — [ResearchGate record](https://www.researchgate.net/publication/270742220_Thermal_Protection_of_Vector-Controlled_IM_Drive_Based_on_DC_Current_Injection)

**Flux-based magnet temperature and fusion**
- Rotor temperature can be obtained indirectly from PM flux linkage because remanence falls with temperature; an online PM-flux estimator based on the current response to SVPWM has been proposed (J. Eng., 2019) — [DOAJ record](https://doaj.org/article/accca5986bd04e3e88eaeb902dd7b133)
- AIT (Austrian Institute of Technology): two combined observers — an electrical-model observer estimating magnet temperature via PM flux linkage and a thermal-model observer — claimed accurate and robust under varying cooling conditions (no K figure in snippet) — [AIT publication record](https://publications.ait.ac.at/de/publications/temperature-estimation-in-pmsms-via-combined-direct-and-indirect-/)
- Sensorless-observer context: PM flux linkage decreases and stator resistance increases at high temperature, and inductances vary with saturation, so online parameter estimation also improves position/speed estimator quality (2024–2025 papers) — [Automatika 2024 (DOAJ)](https://doaj.org/article/43d02a0ed95a4517af8af039f656388f); [Electrical Engineering 2025](https://link.springer.com/article/10.1007/s00202-025-03056-0)

### Inferences
- **I²t with cooling term vs LPTN:** an I²t integrator is a one-node thermal model with fixed thermal resistance and an assumed ambient. The literature's 5–8 K figures for 2–4-node LPTNs are obtained on liquid-cooled automotive machines with measured coolant temperature as the boundary condition. A hair-dryer motor is cooled by its own airflow, whose temperature is ambient and whose mass flow collapses when the inlet is blocked. The practical upgrade path is therefore a 2-node model (winding, stator/housing) whose winding-to-air conductance is scheduled on speed and reduced when the blocked-airflow detector (Section 4) fires, with losses from i²R(T) plus a speed-dependent iron/windage term. Expected accuracy on this product cannot be quoted from the literature; it must be identified against thermocouple-instrumented samples.
- **Ambient handling:** the only temperature sensor is an NTC near the power module, which reads board self-heating plus air temperature. At power-up after a long off-time it approximates ambient; storing the last estimated winding temperature and a coarse off-time proxy (NTC decay) in EEPROM/RAM is the usual way to avoid resetting the thermal state to "cold" on rapid power cycling (design inference; no source found describing this for hair dryers).
- **Resistance-based estimation on this drive — feasibility: marginal.** Copper resistance changes ≈0.39 %/K (standard material value), so ±5 K needs ≈±2 % resistance accuracy. All cited DC-injection papers identify inverter dead-time/non-linearity as the dominant error and need special cancellation (dual winding sets, double dead-time, LUTs). On a mains-bus (≈160–325 V) drive with a low-resistance high-speed winding, the injected-DC voltage is a tiny fraction of bus voltage, shunt-amplifier offset matters, and at 110 krpm R·i is a small part of the voltage equation. A more credible variant for this product is a **standstill R measurement** (DC current vector for tens of milliseconds right before start and/or right after stop), using an EOL-stored per-unit R at known temperature as reference; this gives a calibration point for the thermal model rather than continuous tracking. No source demonstrates either variant on a ≥100 krpm appliance motor.
- **Flux-based magnet temperature:** feasible as a by-product of the ψ_PM estimate in Section 3, with the same ambiguity (thermal vs irreversible loss). NdFeB/ferrite temperature coefficients would convert a ≤5 %-accurate flux estimate into a coarse (tens of K) magnet-temperature indication — adequate only as a gross over-temperature or cross-check signal.
- **Kalman-filter fusion:** the published hybrids (thermal model + electrical-parameter observer) reduce to a low-order filter; a 2-state fixed-point Kalman or even a complementary correction (thermal model state nudged by occasional R or ψ measurements) fits an M0 at a 10–100 ms rate.

### Gaps
- **Commercial implementations:** no documented example of LPTN- or resistance-based winding-temperature estimation in a commercial appliance drive or motor-control SDK was found in this session (queries on TI InstaSPIN Rs-online, vendor SDK thermal models and industrial-drive motor thermal models were not executed — budget).
- No accuracy data for any sensorless thermal method on air-cooled, ≥100 krpm, ~100 W-class motors.
- Quantitative accuracy of the Wilson 2010 method and of the Wallscheid 2021 review's comparison tables could not be read (fetch blocked).

## 6. Over-current / short-circuit protection best practice: response times, soft/two-level turn-off, retry and latch, fuse and DC-link energy coordination, preventing explosive package failure

### Takeaway
IPM vendors converge on a shunt-plus-RC-filter comparator trip that interrupts a short circuit within about 2 µs (RC ≈1.5–2 µs, 1 µs recommended by ROHM) with the trip level set no higher than ≈1.7–2× rated current, low-side-only shutdown, and a fault output whose pulse length tells the MCU what tripped; the team's 6 A / ~1.3 µs comparator is inside that envelope. Published fuse-coordination guidance (let-through I²t below the semiconductor's case-rupture I²t, DC-link capacitor energy as the driver) is written for IGBT modules in industrial converters; no equivalent quantitative guidance for small appliance inverters was found.

### Cited Findings

**Comparator / ITRIP timing and thresholds (production IPM datasheets and application notes)**
- ROHM IPM application notes (several TechWeb pages were returned; which page carries which figure is unverified): on a short-circuit trip all low-side IGBTs are turned off and FO is asserted; SCP acts only on the lower arm; the shunt RC time constant should be set so current is shut off within 2 µs (1.0 µs recommended); IPM internal delay 0.65 µs max; recommended SCP threshold ≤1.7× rated current — [ROHM TechWeb](https://techweb.rohm.com/product/power-device/igbt/17159/); [ROHM TechWeb (SCP setting)](https://techweb.rohm.com/product/power-device/igbt/18469/)
- ROHM: the FO low-level duration differs by protection type so the MCU can identify which protection fired; shortest FO time for SCP is 45 µs; an RC on FO can stretch the low-side off interval — [ROHM TechWeb](https://techweb.rohm.com/product/power-device/igbt/18444/)
- Mitsubishi DIPIPM / SLIMDIP: SC protection senses the low-side DC-bus current through an external shunt with RC filtering; recommended RC time constant 1.5–2.0 µs so the IGBT shuts down within ≈2 µs; CIN trip reference typ. 0.48 V; all low-side IGBTs off and Fo output on trip; choose the shunt so the SC trip level is below 2.0× the current rating (one part: <8.5 A); "SC interrupting time might vary with the wiring pattern" so evaluation on the real system is required (DIPIPM Ver.3 note 2009; DIPIPM+ note June 2025) — [Mitsubishi DIPIPM Ver.3 app note](https://orgnew-www.mitsubishielectric.com/semiconductors/powerdevices/application_notes/dipv3-e.pdf); [Mitsubishi DIPIPM+ app note](https://www.mitsubishielectric.com/semiconductors/powerdevices/application_notes/dipipm_plus_e.pdf); [SLIMDIP-L note (Scribd)](https://www.scribd.com/document/656939031/slimdip-l-e)
- Infineon CIPOS Mini IGCM06G60GA: ITRIP threshold typ. 0.47 V, ITRIP input noise filter ≈530 ns, over-current shuts down all gate-driver outputs, fault-clear time min. 40 µs — [IGCM06G60GA datasheet](https://img.pcbx.com/dev/file/part/spec/IGCM06G60GA-Infineon.pdf)
- Infineon IRS2136 gate driver: blocking time after an over-current event is set by an RC on RCIN (internal 2.8 µA source); Infineon 2EDL23 EiceDRIVER note AN2015-07: ≈2.1 µs typical from ITRIP event to fault-pin change, fault-clear time set by external capacitor — [IRS2136 datasheet](https://www.infineon.com/assets/row/public/documents/24/49/infineon-irs2136ds-datasheet-en.pdf); [EiceDRIVER EN-/FLT note](https://www.mouser.lt/pdfDocs/Infineon-EiceDRIVER_Advanced_use_of_pin_EN-FLT-ApplicationNotes-v01_00-EN.pdf)

- Power Integrations BridgeSwitch: cycle-by-cycle current limit on both low-side and high-side FETs in hardware, described as fail-safe and redundant — [PI white paper W006](https://www.power.com/sites/default/files/documents/pi_whitepaper_w006_simplified_product_safety_certification_through_hardware_based_motor_fault_protection_with_bridgeswitch.pdf)
- Dyson patents: a current controller for an electric machine generates an over-current signal against a threshold derived from a stored scaling factor so that component tolerances do not affect the trip point (GB0905879 family; US 9,742,319 granted 2017) — [GB0905879D0](https://patents.google.com/patent/GB0905879D0/en); [US9742319](https://uspto.report/patent/grant/9742319)

**Soft / two-level turn-off**
- Fuji IPM: on protection-initiated turn-off the gate voltage is reduced gradually (soft turn-off) to suppress surge voltage and avoid destroying the IPM — [Fuji MT6M15962](https://www.fujielectric.com/products/semiconductors_devices/semiconductor/product_series/MT6M15962b_EN_03.pdf)

- A vacuum-cleaner diagnostics patent describes shutting the motor down and restarting it as a deliberate recovery action for blockage (US 2014/0312813 A1) — [US20140312813A1](https://patents.google.com/patent/US20140312813A1/en)

**Fuse / DC-link energy / rupture coordination**
- Mersen: the total I²t let through by the fuse while clearing must be less than the I²t that damages the protected system; for IGBT modules the relevant limit is the I²t that causes case rupture — [Mersen fast-acting fuse article (2018)](https://ep-ca.mersen.com/sites/mersen_ca/files/2018-11/AR-Fast-Acting-Fuses-For-Semiconductor-Protection-Article.pdf)
- Rockwell (1997): IGBT module rupture tested under over-current failure and unclamped-voltage failure; the two modes give different rupture energy and I²t; a DC-link bus fuse is used in most designs to limit rupture — [record](https://manuscript.isc.ac/Inventory/49/316905.htm)
- Aalborg University: with large DC-link stored energy, even with active (gate) protection a high-power IGBT can still rupture/explode in a failure condition; experiments show high-speed fuses can prevent explosion, at the cost of added DC-link inductance — [AAU publication](https://vbn.aau.dk/en/publications/high-speed-fuses-in-igbt-based-voltage-source-converters); [AAU "IGBT fuses for protection against explosion"](https://vbn.aau.dk/da/publications/igbt-fuses-for-protection-against-explosion-in-voltage-source-con)
- 2022 paper on VSC-based DC systems: the capacitor-discharge I²t must exceed the fuse melting I²t (enough capacitance) for the fuse to clear; a normalised I²t map is given — [catalogue record](https://katalog.lib.cas.cz/KNAV/EdsRecord/edsair,edsair.doi...........10f19dda07e29791db7ac9b8dac0f6c4)
- Dynex AN6442 covers fuse protection of IGBT modules against rupture — [Dynex AN6442](https://dynexsemi.com/Portals/0/PDF/DNX_AN6442.pdf)
- Appliance abnormal-operation acceptance criteria as summarised by a Chinese explainer of GB/T 4706.15-2024 clause 19: no fire, no molten live parts emitted, enclosure does not crack so as to create shock risk — [Sohu explainer](https://m.sohu.com/a/954168872_121327213/?pvid=000115_3w_a&scm=10001.8085_13-8085_13.0.0-0-0-0-0.0)

### Inferences
- The team's hardware trip (6 A, ~1.3 µs) sits within the vendor envelope (≤2 µs to interruption, 1 µs preferred). The vendors' sizing rule — trip ≤1.7–2× device rated current — should be checked against the actual power stage rating; 6 A is ≈5–10× the ~0.5–1 A phase current implied by 130 W on a rectified-mains bus (my estimate), so the comparator is a pure short-circuit/shoot-through trip and the software power/I²t limits cover overload, which is the usual two-tier arrangement.
- Mitsubishi's warning that "SC interrupting time varies with wiring pattern" and the low-side-only shunt topology imply two residual cases to test on the real board: (a) high-side-to-ground/phase-to-earth faults that bypass the low-side shunt, and (b) total loop delay including comparator, filter, gate driver and FET turn-off.
- Soft/two-level turn-off guidance is aimed at high-inductance, high-current IGBT/SiC modules; for a ~1 A, low-loop-inductance MOSFET/IPM stage the relevant practice is whatever the IPM/driver integrates (Fuji-style soft shutdown). DESAT is explicitly not recommended for standard Si MOSFETs — shunt-comparator protection is the appropriate choice.
- Rupture coordination transfers in principle: the energy available to an internally failed bridge is the DC-link capacitor energy (½CV², delivered in microseconds, before any mains fuse can act) plus mains follow-through limited by the input fuse's let-through I²t. Hence (i) the bulk capacitor value and bus voltage bound the "instant" energy, and (ii) the input fuse (or fusible resistor) must have a let-through I²t below what the PCB/package tolerates without emitting flame or molten metal. Appliance practice is to verify this empirically in the clause-19 component-fault tests rather than by calculation; no appliance-scale rupture-I²t data were found.
- Retry policy inference from the cited commercial behaviours: transient/soft faults (start-up failure, loss-of-sync) → bounded automatic retries; hardware over-current → count events and latch after N within a window (EP 2415151 pattern), requiring a power cycle; log every trip to EEPROM (Section 8). No source gives recommended N or window values.

### Gaps
- Published, quantitative guidance on preventing explosive package failure for small SMD MOSFETs / low-power IPMs (rupture I²t, maximum DC-link energy) was **not found**; all rupture literature located concerns industrial IGBT modules. Query on appliance-scale fuse/bulk-capacitor coordination was not executed (budget).
- Littelfuse/Bussmann semiconductor-fuse selection guides: not retrieved.
- IEC 60335-1 clause 19.11.2 (electronic-component fault conditions) and 19.11.4 text: not retrieved; only the existence of these clauses and the 2004 amendment that introduced protective-electronic-circuit requirements were confirmed — [IEC 60335-1 A1:2004 abstract](https://standards.iteh.ai/catalog/standards/iec/d616da51-b90e-421e-b6a6-9b919c6dac6f/iec-60335-1-2001-amd1-2004)
- Recommended retry counts/lock-out timings in vendor application notes: query not executed (budget).
- onsemi and ST (SLLIMM "smart shutdown") specifics were not retrieved.

## 7. Bearing and mechanical fault detection with a low-cost accelerometer or current-signature analysis at 100k+ rpm; imbalance detection

### Takeaway
No source was found that demonstrates bearing-fault detection on a ≥100,000 rpm appliance motor with either a MEMS accelerometer or motor-current signature analysis. General guidance says early bearing damage appears above 5–10 kHz and that sensor bandwidth should be 40–50× shaft frequency — about 73–92 kHz at 110 krpm — far beyond the 8–16 kHz of current wideband MEMS parts; a low-cost on-board accelerometer is therefore credible for 1× imbalance/looseness trending (if its bandwidth exceeds 1.83 kHz) but not for classical early bearing-defect diagnosis.

### Cited Findings
- Early bearing failure can show as high-frequency components above 5 kHz; a 3-axis MEMS accelerometer with bandwidth up to 16 kHz (ADXL383 class) exists, but doubling bandwidth from 8 kHz to 16 kHz "does not mean fault-detection performance will double" (Macnica, on Analog Devices parts) — [Macnica article](https://www.macnica.co.jp/en/business/semiconductor/articles/analog_devices/150275/)
- Analog Devices: vibration sensor performance up to 10 kHz and beyond is recommended because bearing resonances are typically in the multi-kilohertz range regardless of rotational speed — [Analog Dialogue](https://www.analog.com/en/resources/analog-dialogue/articles/choosing-the-best-vibration-sensor-for-wind-turbine-condition-monitoring.html)
- Sensata: accelerometer bandwidth is "the single most important factor" for early-stage bearing-fault detection; MEMS generally has a higher noise floor than piezoelectric; comparison table lists piezo 15 kHz vs MEMS 8 kHz — [Sensata white paper](https://www.sensata.com/sites/default/files/a/sensata-understanding-accelerometer-vibration-part2-whitepaper.pdf)
- A field reference citing a TE Connectivity white paper recommends 40–50× shaft RPM as the lower bound for usable sensor bandwidth — [Industrial Monitor Direct](https://industrialmonitordirect.com/blogs/knowledgebase/predictive-maintenance-with-vibration-sensors-pdm-field-reference)
- Frontiers in Mechanical Engineering (2026): high-frequency descriptors should be recomputed only within the experimentally verified passband of the bearing sensor, with piezo re-measurement where needed — [Frontiers 2026](https://www.frontiersin.org/journals/mechanical-engineering/articles/10.3389/fmech.2026.1979480/full)
- MEMS accelerometers have been used for multi-fault rolling-bearing diagnosis on three-phase induction motors (conventional speeds) — [ResearchGate record](https://www.researchgate.net/publication/282389149_Application_of_MEMS_Accelerometer_for_Detection_and_Diagnosis_of_Multiple_Faults_in_the_Roller_Element_Bearings_of_Three_Phase_Induction_Motor)
- Vendor demos: TI states the F28P55x NPU enables motor-bearing-fault detection and lists "blower imbalance detection" among use cases with "up to 99 %" accuracy (vendor claim, CNN on vibration data); ST has a "fan anomaly detection based on vibrations" NanoEdge case study — [TI C2000 overview](https://www.ti.com/microcontrollers-mcus-processors/c2000-real-time-control-mcus/overview.html); [ST case study](https://www.st.com/content/st_com/en/st-edge-ai-suite/case-studies/fan-anomaly-detection-based-on-vibrations.html)
- EOL practice treats noise/vibration, rotor balance and bearing condition as production test items (Section 9) — [Marposs](https://www.marposs.com/eng/application/end-of-line-testing-of-electric-motors)

### Inferences
- Numbers for this motor: shaft frequency 1833 Hz at 110 krpm. The 40–50× rule gives 73–92 kHz required bandwidth; even the "≥5–10 kHz" guidance equals only ≈3–5× shaft frequency here. Ball-bearing defect frequencies are multiples of shaft frequency (typically a few × for BPFO/BPFI), i.e. already in the 5–10 kHz range before any harmonics or resonance bands. Conclusion: classical envelope analysis is out of reach for a consumer MEMS part sampled by an M0.
- What the on-board accelerometer can do (**M0-feasible**): (a) 1× synchronous amplitude — demodulate the accelerometer signal with the FOC rotor angle (sin/cos of θ_e, which equals mechanical angle on a 2-pole machine) and low-pass; this is a lock-in measurement needing no FFT and directly measures imbalance; it requires accelerometer bandwidth/ODR comfortably above 1.83 kHz (≥4–5 kHz ODR) or evaluation at a lower "check" speed during run-up/coast-down; (b) broadband RMS and crest factor in the available band, trended against the per-unit EOL baseline in EEPROM; (c) drop/impact event detection (large-g transient while off or running) logged as a precursor of bearing/rotor damage. If the accelerometer is a ≤1.6 kHz-ODR consumer part, 1× at top speed aliases; measuring at a defined sub-speed or using deliberate, known aliasing are the only options — to be confirmed against the actual part number (not provided).
- Sub-synchronous or broadband vibration growth and a rise in friction loss (higher q-axis current / input power at a given speed with unblocked airflow, or shorter coast-down time) are the bearing-wear indicators available without high-bandwidth sensing; coast-down time after switch-off can be measured for free from back-EMF frequency while the MCU is still powered (design inference, no source).
- MCSA: bearing faults modulate torque at defect frequencies; with a tiny rotor inertia and kHz-range defect frequencies above the current-loop bandwidth, signatures would have to be read from current ripple sampled at only ~10–20 samples per electrical cycle. No evidence was found that this works at this speed class.

### Gaps
- **Not found:** any published bearing- or imbalance-detection result at ≥100 krpm in hair dryers/vacuums; any MCSA-vs-vibration sensitivity comparison for small high-speed PMSMs (queries not executed — budget).
- Imbalance detection thresholds (e.g. ISO balance grade vs 1× acceleration) for hair-dryer motors: not found.
- Whether any commercial hair dryer uses its accelerometer for motor-health monitoring (as opposed to orientation/drop detection) was not found.

### Inferences
- **Production-proven vs demo (as far as evidence found):** production-proven = hardware fault reporting from IPMs/driver ICs and rule-based protections; vendor demo = all four edge-AI motor-health offerings above (accuracy figures are vendor-reported on vendor-made datasets, with "anomalies" such as changed speed or modified start-up parameters that are far easier than real incipient faults); lab = ML ITSC detection.
- **Feasibility on Cortex-M0, 128 KB flash, no connectivity:** the footprints quoted for anomaly-detection libraries (≈3–4 KB flash, <1 KB RAM) fit easily; the constraint is not memory but (i) feature computation at 1.8 kHz fundamental (FFT of accelerometer/current on an M0 competes with the FOC loop; lock-in/Goertzel features at 1×/2× are cheap), and (ii) no OTA — the model and thresholds are frozen at manufacture, so on-device learning or per-unit baselining at EOL / first-use is the only way to adapt to unit-to-unit spread. A statistical baseline (per-unit mean/variance of ~6–10 scalar health indicators stored in EEPROM, z-score or Mahalanobis-distance alarm) delivers the same function as a "TinyML anomaly detector" with deterministic, certifiable behaviour.
- **Black box without connectivity (design inference):** the useful minimum is a wear-levelled EEPROM ring buffer containing lifetime counters (run hours, starts, hours per speed/heat mode), last-N fault records (fault code, speed, bus voltage, phase-current magnitude, NTC, estimated winding temperature, time-since-start), peak-hold values (max NTC, max bus voltage, max estimated winding temperature, max shock-g), trend snapshots of health indicators (2f/negative-sequence index, ψ_PM, P(ω) deviation, 1× vibration, coast-down time) and the EOL fingerprint. "Fleet analytics" then happens at the service/returns bench by reading the log over the production test interface. Writing the record must be completed from hold-up energy after a trip; EEPROM endurance bounds the trend-snapshot rate. No public description of such a scheme for a specific consumer product was found.
- Keeping any ML/anomaly function strictly advisory (logging, user hint, derating) and outside the Class B safety functions avoids having to certify it under Annex R (inference from Section 1's re-evaluation requirement).

## 9. End-of-line (EOL) testing and screening for small motors and drive assemblies; reliability qualification practice for hair dryers

### Takeaway
Commercial EOL practice for small BLDC stators/motors is a standard menu — AC hipot, insulation resistance, surge (impulse) turn-to-turn test with waveform comparison (increasingly with impulse partial-discharge detection), DC resistance, inductance, rotation/phase sequence, driven back-EMF (Ke and waveform), load/no-load performance, missing-phase, noise/vibration and balance — with results logged to MES for traceability; Chinese vendors (AIP 艾普, HIOKI China, ZC) sell integrated stations. For hair-dryer qualification, the governing documents were identified (IEC 60335-2-23 Ed. 7:2026; GB/T 4706.15-2024; QB/T 1876-2023; T/CHEAA 0022-2023), but life-test hours and clause-19 test details could not be retrieved.

### Cited Findings

**EOL test content**
- Marposs: insulation testing is typically repeated at end of line (insulation resistance, hipot, surge, or partial-discharge measurement) to confirm assembly did not damage insulation; EOL also covers NVH and back-EMF — [Marposs EOL testing](https://www.marposs.com/eng/application/end-of-line-testing-of-electric-motors)
- AIP BLDC stator tester items: AC hipot, insulation resistance, surge, DC winding resistance, inductance, rotation, back-EMF, phase sequence, Hall characteristics — [AIP stator tester](https://www.aiptesting.com/bldc-motor-stator-tester.html)
- AIP BLDC motor tester: back-EMF test checks stator–rotor fit; speed setting range 200–3000 rpm, recommended 1000 rpm — [AIP motor tester](https://www.aiptesting.com/bldc-motor-tester.html)
- AIP (艾普) back-EMF method: drive the motor under test with a servo or clutch to a set speed, capture three-phase back-EMF with differential probes and a ≥1 MHz DAQ, compute the back-EMF constant and compare with design; back-EMF exposes latent defects such as magnet demagnetisation and winding shorts — [AIP 艾普 back-EMF article](https://www.aipuo.com/news/1305.html)
- AIP brushless motor test system: integrates hipot, insulation, turn-to-turn (匝间) impulse, DC resistance, load test (power, speed, Hall) and missing-phase (缺相) detection with pass/fail indication; composed of fixture, industrial PC, test host, software and function modules; can interface to MES for traceability — [AIP 无刷电机测试系统](http://aipuo.com/products/128.html); [AIP 无刷电机测试项目](http://www.aipuo.com/active/691.html)
- Generic BLDC test guides group checks as electrical (resistance, inductance, insulation, sensors, back-EMF) and mechanical/NVH (noise, vibration, balance, bearing condition); surge test targets turn-to-turn insulation weakness — [SD Motor testing guide](https://sdmotorcustom.com/bldc-motor-testing/)
- Motor noise arises from electromagnetic, mechanical and aerodynamic sources; factory noise checks and 3-axis accelerometer + spectrum analysis are typical; rotor dynamic-balance precision is a monitored parameter (third-party lab description) — [中析研究所](https://www.yjssi.com/showinfo-4-72024-0.html)

**Surge / partial-discharge testing**
- HIOKI: turn-to-turn testing emulates inverter surge stress, so impulse waveforms are used for impulse partial-discharge testing; the ST4200 PD detector handles both AC PD and impulse PD (2025 brochure) — [HIOKI ST4200 样本](<https://hioki.cn/uploads/video/20250317/9d8459a3bd8cbed1ad964a8fdebf9850/ST4200，SW2001样本.pdf>)

### Inferences
- **Per-unit fingerprint for this product (inference from the vendor test menus):** at stator level — R per phase (and R imbalance), L per phase, surge waveform vs golden unit, hipot/IR; at motor level — driven back-EMF Ke and phase symmetry; at drive-assembly/final level — the product's own firmware can self-measure and store in EEPROM: phase R (standstill DC vector), current-sensor offsets and gain plausibility, ψ_PM/Ke from the observer at a reference speed, negative-sequence/2f baseline, P(ω) curve at 2–3 speed points with defined airflow, 1× vibration and broadband RMS, coast-down time, NTC reading vs station ambient. These are the baselines the on-line detectors in Sections 2, 3, 4 and 7 need, and writing them at EOL together with a serial number gives traceability between MES and the field black box.
- AIP's standard back-EMF test range (200–3000 rpm) confirms that Ke screening is done at low driven speed; nothing found indicates catalogue EOL stations spin 110 krpm motors externally — high-speed checks (vibration, noise, power, speed) have to be self-driven run tests on the finished motor/drive.
- Surge-with-PD testing is described for inverter-fed (surge-stressed) insulation; for a few-turn, low-voltage-per-turn hair-dryer stator the surge waveform-comparison test mainly screens for shorted turns and gross insulation damage; whether PD screening adds value at this voltage class was not addressed by any source found.
- Run-in/burn-in: no source located states durations; a short self-driven run that also captures the fingerprint is the minimum consistent with the cited practice.
